# KONTROL ERP - Fleet Management & Governance
**Une Solution Innov'Korp**

## 💎 Vision & Identité
**KONTROL** n'est pas un simple logiciel de gestion. C'est le système nerveux central des entreprises à haute croissance, conçu par **Innov'Korp**. Notre vision est d'éliminer la latence décisionnelle en fusionnant l'intelligence artificielle et une architecture polyglotte ultra-sécurisée.

## 🏛 Architecture Tech (The Hive - V2)
KONTROL repose sur une structure distribuée ultra-indexée assurant une latence < 10ms :

- **Java Spring Core** : 
  - `GovernanceAnalyst.java` : Monitoring MRR & Ecosystem.
  - `TiersManager.java` : Gestion des entités fiscales.
  - `ChargesManager.java` : Orchestration des flux de dépenses.
  - `StockMovementManager.java` : Traçabilité des flux physiques.
- **Python Neural Brain** : 
  - `NeuralOrchestrator.py` : Ensemble Qwen/Gemini/DeepSeek simulant des neurones humains pour l'analyse prédictive.
- **Rust Shield** : Validation atomique de chaque transaction via `MemoryShield.rs`.
- **Go Gateway** : Signature HMAC L7 et filtrage des accès API.
- **PostgreSQL Engine** : Schéma relationnel complet indexé pour la performance.

## 🚀 État du Système (Indexé)
- **Dashboard** : KPIs temps-réel (Java Mirror).
- **Stocks** : Analyse de valorisation instantanée.
- **Finance** : Bridge financier éligible via Spring Boot.
- **Communication** : K-Chat crypté par Rust.
- **IA Blue** : Cerveau multi-modèles (Python Backend).
